# Project Automata

[English](README.md)

## An Intelligence With No Boundaries

> 知性無き者への救済を。

Project Automata は、個人開発者の Midorin（みどりん）が率いる取り組みです。Midorin はサイバーセキュリティと機械学習、特に言語モデルと分類モデルを主な専門分野とし、AI の発展、オープンソースへの貢献、継続的な学習に取り組んでいます。

詳しくは[公式サイト](https://www.suwako.me/)と [About ページ](https://www.suwako.me/about)をご覧ください。

## プロジェクト

### [Chandelier UI](https://github.com/midorin-Linux/ChandelierUI)

**ステータス：進行中**

Chandelier UI は、Project Automata で使用するチャットインターフェースです。現在開発を進めています。

詳細は [Chandelier UI のリポジトリ](https://github.com/midorin-Linux/ChandelierUI)をご覧ください。Project Automata のプロジェクトは、公式サイトの [Production ページ](https://www.suwako.me/production)でも紹介しています。
